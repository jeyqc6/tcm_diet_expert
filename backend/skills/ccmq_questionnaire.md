# CCMQ 简版问卷题库与计分口径

⚠️ **来源说明**：本文件的题目文字是本项目改写的简化版，不是《中医体质分类与判定》标准
（中华中医药学会标准）官方 60 条量表的逐字复刻——官方量表是受版权保护的标准化文件，本
项目没有可靠的逐字原文来源，且"简版、每轮 2-3 题分批收集"的定位本身也不需要满 60 题。
**计分公式和判定阈值忠实对照公开发表的官方标准**（见下），不是本项目发明的；改写的只是
条目文字本身，用于对话式简版问卷。九类体质名称、转化分公式、判定阈值均与
`docs/ARCHITECTURE.md` §11.3 一致，实现见 `backend/onboarding/ccmq_scoring.py`。

## 评分量表（5 级李克特量表）

题干是描述，选项问「这句话有多符合你」。对话主答法是打 1-5；文字答法仍可识别：

| 数字 | 含义 | 官方频率词（仍可作答） |
|---|---|---|
| 1 | 完全不像 | 没有（根本不） |
| 2 | 不太像 | 很少（有一点） |
| 3 | 有些像（不确定也记 3） | 有时（有些） |
| 4 | 比较符合 | 经常（相当） |
| 5 | 非常符合 | 总是（非常） |

## 九类体质题库（每类 5 条，共 45 条）

对话式收集时每轮抛 2-3 条，不要求用户一次性回答完；允许"不确定"（记 3 分，即中性值，
不强迫用户凑一个偏向性答案）。题干用白话；中医术语放在括号里，计分含义不变。

**Executable copy (zh + en) lives in `backend/onboarding/flow.py` `ITEM_TEXTS` /
`ITEM_TEXTS_EN`.** Stems below are the Chinese human-readable twin; keep scoring
identical when editing. English UI uses the parallel 45 stems in `ITEM_TEXTS_EN`
(same order, same 1-5 Likert).

### 平和质（ping_he）
1. 您平时精力充沛吗？
2. 您睡觉踏实、夜里睡得安稳吗？
3. 您换季时身体适应得好、不容易感冒吗？
4. 您情绪比较平稳，遇事不容易烦或慌吗？
5. 您觉得自己身体状况总体不错吗？

### 气虚质（qi_xu）
1. 您容易疲乏，稍微活动就觉得喘气费劲(气短)吗？
2. 您说话声音偏小、不太想多说话吗？
3. 您容易出汗，稍微活动就出汗明显吗？
4. 您容易感冒，而且感冒后恢复得慢吗？
5. 您比别人更容易喘气费劲、感觉气接不上来吗？

### 阳虚质（yang_xu）
1. 您手脚发凉，比别人更怕冷吗？
2. 您吃(喝)凉的东西会不舒服，或者容易拉肚子(腹泻)吗？
3. 您比别人更容易着凉、容易感冒吗？
4. 您提不起精神，做事缺少热情吗？
5. 您比一般人更怕冷，需要比别人穿更多衣服吗？

### 阴虚质（yin_xu）
1. 您感觉手心、脚心发热吗？
2. 您皮肤或嘴唇容易干燥吗？
3. 您容易口干、嗓子发干、想喝水吗？
4. 您大便干燥，不容易排出吗？
5. 您容易失眠、晚上睡不安稳吗？

### 痰湿质（tan_shi）
1. 您感觉身体沉重、不轻松吗？
2. 您觉得肚子摸上去软软的、偏胖(腹部肥满松软)吗？
3. 您额头或脸上出油比较多吗？
4. 您舌头上那层苔又厚又黏、嘴里不清爽(舌苔厚腻)吗？
5. 您皮肤油腻，出的汗黏黏的、不太干爽吗？

### 湿热质（shi_re）
1. 您脸上或鼻子感觉油油的、亮亮的吗？
2. 您容易长痘(痤疮)或皮肤上起疖子、疙瘩(疮疖)吗？
3. 您感觉嘴里发苦，或有异味吗？
4. 您大便黏、解不干净吗？
5. 您小便颜色发黄、气味比较重吗？

### 血瘀质（xue_yu）
1. 您皮肤容易不明原因地出现淤青吗？
2. 您脸颊靠近鼻子两侧(两颧)有细细的红血丝吗？
3. 您身上某个地方会刺痛，而且总在同一个位置吗？
4. 您嘴唇颜色偏暗吗？
5. 您容易忘事、刚做过的事也记不住吗？

### 气郁质（qi_yu）
1. 您觉得闷闷不乐、情绪低落吗？
2. 您容易紧张、感到焦虑不安吗？
3. 您胸口两侧或肋骨附近(胸胁)、或者乳房有胀痛感吗？
4. 您容易无缘无故叹气吗？
5. 您嗓子眼总感觉有东西堵着吗？

### 特禀质（te_bing）
1. 不感冒的时候，也会打喷嚏、鼻塞、流鼻涕吗？
2. 您容易对药物、食物、气味或花粉等过敏吗？
3. 您的皮肤容易起风团、风疙瘩(荨麻疹)吗？
4. 您皮肤会因为过敏出现紫红色的小点或青紫斑吗？
5. 您的皮肤只要一抓就红，并留下抓痕吗？

## 计分与判定

原始分 = 该体质类型 5 条题目分值之和(范围 5-25)。

转化分 = [(原始分 - 5) / (5 × 4)] × 100，范围 0-100，恰好在原始分 11/13/17 时得到
转化分 30/40/60 这三个判定边界值(整数，无需四舍五入)。

- **8 种偏颇体质**(气虚/阳虚/阴虚/痰湿/湿热/血瘀/气郁/特禀)：转化分 ≥ 40 → "是"；
  30-40 → "倾向是"；< 30 → "否"。
- **平和质**(单独一套规则)：转化分 ≥ 60 且其他 8 种体质转化分均 < 30 → "是"；
  转化分 ≥ 60 且其他 8 种体质转化分均 < 40(不满足上一条) → "基本是"；否则 → "否"。

多个体质同时达到候选门槛("是"/"基本是"/"倾向是")是正常结果("体质夹杂")，不是异常，
取分最高的一个写入 `constitution`(主)，其余候选写入 `constitution_secondary`(次)。

## "不确定"选项的处理

用户选择"不确定"时记 3 分(量表中点，既不算倾向也不算不倾向)，不强迫用户在没有把握时
凑一个方向性答案；分批收集时允许用户跳过整个体质分支的剩余题目，跳过的题目同样记 3 分。
