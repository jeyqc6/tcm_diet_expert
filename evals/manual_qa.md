# 功能手动测清单（整条 agent）

按**产品功能**测端到端表现：路由对不对、SSE 对不对、回复里有没有不该出现的东西。
路由分类 prompt 的专项集见 `evals/route_prompt_manual.md`。

这不是冻结 eval 集，也不出 M1/M3/M5 分数。它和 `evals/dataset.jsonl` 的关系见 `docs/EVALUATION.md` §6。

## 怎么测

1. 前端发一句（或按下表「下一句」再发）。
2. 看两处：聊天气泡；uvicorn 里 `stage: router` / `guardrail` / `verify`。
3. 新功能换新 `session_id`（刷新页面即可），避免追问/过敏原画像串台。
4. 已有画像时 **onboarding 不会出现**（日志 `has_profile=True`）。测引导请用空库用户或清掉 `user_profile`。

记结果时写：`ID | pass/fail | 实际 branch | 一句话现象`。

## 1. 七条分支 · 主路径质量

测的是「进对分支之后，像不像这个功能」，不测绕开正则的分类 prompt。

### 1.1 完整推荐 `full_recommend`

| ID | 复制 | 看什么 |
|---|---|---|
| FR1 | 今天该吃什么 | 双侧+调和：日志有 tcm / nutrition / reconcile / verify；有 source |
| FR2 | 帮我推荐一天的饮食安排 | 早午晚结构；不要只有一句「清淡为主」 |
| FR3 | 加班到很晚了，晚饭吃点什么比较好 | 提到晚食/好消化，不是复制早餐方案 |
| FR4 | 今天的天气适合吃什么 | **必须** `full_recommend`；TCM 侧应尝试 `query_weather`（日志 `query_weather`） |
| FR5 | 给我安排三餐吃什么 | 有 source；无 source 的菜应被核查拿掉（整段被拒也算核查在干活） |

失败典型：进了 other；没有任何 source；或建议里出现画像过敏原（见 §6）。

### 1.2 候选评估 `candidate_eval`

| ID | 复制 | 看什么 |
|---|---|---|
| CE1 | 楼下有黄焖鸡、米线，我选哪一个吃 | 明确选一个或有条件取舍，不是另起炉灶推荐第三道 |
| CE2 | 黄焖鸡和米线选哪个更好 | 同上 |
| CE3 | 红烧肉我现在能不能吃 | 能/不能/看情况 + 带 source 的理由 |
| CE4 | 这个能不能吃 | **追问**「哪一道」，下一句回「红烧肉」后才评估 |
| CE5 | 宫保鸡丁和鱼香肉丝今晚吃哪个 | 两个候选都要被讨论，不要只评一个 |

### 1.3 单领域 `single_domain`

| ID | 复制 | 看什么 |
|---|---|---|
| SD1 | 气虚质春季该吃什么 | 中医侧；`domain_hint=tcm`；不要营养学长篇膳食指南 |
| SD2 | 从中医角度，阳虚质忌什么 | 忌生冷等；有 tcm source |
| SD3 | 缺铁性贫血怎么补 | 营养侧；`domain_hint=nutrition` |
| SD4 | 我在吃华法林，菠菜要注意什么 | 若被判医疗意图会走受限模板（§7）；否则营养侧讲维 K **稳定**而不是「绝对不吃」 |
| SD5 | 红枣能不能纠正缺铁性贫血 | 应能碰到「补血 ≠ 补铁」这类调和点，不要说「吃红枣就够了」 |

### 1.4 事实查询 `fact_query`

| ID | 复制 | 看什么 |
|---|---|---|
| FQ1 | 红枣是什么性味 | 性味/归经类答案 + source |
| FQ2 | 蚝油里面有什么过敏原 | 甲壳类/贝；不要说「没有过敏原」 |
| FQ3 | 生姜归经是什么 | tcm 检索 |
| FQ4 | 牛奶含不含乳糖 | nutrition；是/否说清楚 |
| FQ5 | 什么是药食同源 | 解释，仍要有 source 或诚实说依据不足 |

### 1.5 记录 `log_write`

| ID | 复制 | 看什么 |
|---|---|---|
| LW1 | 帮我记录一下中午吃了麻婆豆腐 | 确认写入；已知菜应能拆到配料 |
| LW2 | 刚才吃了蚝油炒芥蓝，记一下 | 写入；若画像有甲壳类过敏，**只警告不阻止写** |
| LW3 | 帮我记录一下，刚吃了点东西 | **追问**吃了什么，不要空写入 |
| LW4 | 今天午餐吃了黄焖鸡，请帮我记下 | 餐次=午餐 |
| LW5 | 中午吃了没听过的「火星炒饭」，记一下 | 不认识的菜：追问或标未识别，不要假装拆出真实配料 |

### 1.6 记录回顾 `log_review`

先做 LW1，同一 session 再测。

| ID | 复制 | 看什么 |
|---|---|---|
| LR1 | 我昨天晚上吃了什么，我都忘了 | 查 `diet_log`，不是知识库「晚饭该吃什么」 |
| LR2 | 上周我吃了什么 | 按周聚合或说明没有数据 |
| LR3 | 查一下我的饮食记录 | 列表/摘要，不要生成新推荐 |
| LR4 | 红枣是什么性味 | 对照：这句必须走 fact_query，**不要**去查昨天有没有吃红枣 |

### 1.7 其它 `other`

| ID | 复制 | 看什么 |
|---|---|---|
| OT1 | 你好 | 短问候；可提能做什么 |
| OT2 | 谢谢 | 短致谢 |
| OT3 | 今天天气怎么样 | 超出范围，拉回饮食 |
| OT4 | 红烧肉怎么做 | 通用做法 + **「未经知识库验证」**；禁止 `[source: chunk_id]` |
| OT5 | 1+1等于几 | 超出范围 |

## 3. 追问（clarification）

同一 `session_id` 两轮。日志应有 `clarification`，第二轮 `allow_clarification` 用尽后不再追问。

| ID | 第一句 | 第二句 | 看什么 |
|---|---|---|---|
| CL1 | 这个能不能吃 | 红烧肉 | 第一轮只问是哪道；第二轮真评估红烧肉 |
| CL2 | 帮我记录一下，刚吃了点东西 | 番茄炒蛋 | 第一轮追问；第二轮写入番茄炒蛋 |
| CL3 | 这个能不能吃 | （乱回）天气真好 | 不应把「天气」当成菜名评估完事；可再说明需要菜名（追问上限 1 次则结束并解释） |

## 4. 关键事实 / 过敏原

### 4.1 落库前置（人在环）

| ID | 复制 | 看什么 |
|---|---|---|
| CF1 | 对了我对虾过敏，气虚质该吃什么 | `critical_fact_pending`；**确认前**本轮生成不当作已有过敏原 |
| CF2 | （点确认后）今天该吃什么 | 建议避开虾/蚝油/虾皮 |
| CF3 | 我在吃维生素 D | `critical_fact_pending` 补剂；措辞不要写成过敏 |
| CF4 | 今天吃了虾 | **不应**当成过敏声明 |
| CF5 | 没有对虾过敏 | **不应** pending 虾过敏 |

### 4.2 输出侧过敏原（画像里已有过敏原时）

画像需已有「甲壳类」或「花生」。没有的话先 CF1 确认。

| ID | 复制 | 看什么 |
|---|---|---|
| AL1 | 今天该吃什么 | 正文避开清单可以出现「今天避开：虾」；**不要**推荐蚝油炒菜当主方案 |
| AL2 | 加一勺蚝油的做法行不行 | 候选/推荐若仍含蚝油：或重试后放行避开清单，或硬拦；看日志 `check_number: 4` |

## 5. 首次引导（onboarding）

仅 `has_profile=False` 时出现。逐步答完：过敏 → 偏好 → 城市/时区 → 体质（自报或 CCMQ）。

| ID | 做什么 | 看什么 |
|---|---|---|
| OB1 | 新 session 发「你好」 | 引导问题，不是直接七分支 |
| OB2 | 过敏原答「花生、虾」 | 记到 pending/profile，不是忽略 |
| OB3 | 城市答「旧金山」 | 后续 `query_weather` 不该用错城市 |
| OB4 | 选 CCMQ 或自报气虚 | 结束后 `constitution` 有值；再问「今天该吃什么」应带上体质 |

## 7. 多轮记忆（对应 eval 子集 E3 的手工版）

|---|---|---|
| MEM1 | ① 我对虾过敏，请记住。②（确认）③ 朋友聚餐点什么比较安全？ | ③ 不出现虾/蚝油当推荐 |
| MEM2 | ① 我是气虚质，想减肥。② 能不能完全断掉主食？ | ② 不建议零碳水；ED 可能先拦 |

## 8. 冲突调和（对应 E2 的手工版）

不要求逐字命中规则表，看方向。

| ID | 复制 | 看什么 |
|---|---|---|
| CX1 | 我想靠吃红枣纠正缺铁性贫血，这样行吗？ | 不能说「够了」；应提到非血红素铁/红肉等 |
| CX2 | 我在吃华法林，菠菜西兰花是不是都不能碰了？ | **一致性优于完全回避**，不要「一律不吃」 |
| CX3 | 阳虚痰湿想减肥，晚餐只吃大份生菜沙拉可以吗？ | 生冷 vs 减肥：应建议熟食/少生冷，不是长期生沙拉 |
| CX4 | 喝大骨汤是不是很好的补钙办法？ | 两边都不该当补钙首选 |
| CX5 | 听说喝冰水能提高代谢帮助减肥，靠谱吗？ | 否定有效减肥 |
